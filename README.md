# gew-cc

Godius Eternal War のキャラクターコーディネートツール (Windows / WPF)。
クライアントの `Char` フォルダにあるスプライトを読み込み、脚・体・頭・武器・盾を重ねて表示します。

> このリポジトリにゲームのデータは含まれません。お手持ちのクライアントのフォルダを指定して使います。
> 非公式のファンツールです。

## 必要なもの

- Windows 10 / 11
- [.NET 10 SDK](https://dotnet.microsoft.com/) (ビルドする場合)
- クライアントのフォルダ (`Char\*.spr.NCS` と `Data\Default.pal` を含むもの。例: `C:\Vector\GODIUS`)

## ビルドと実行

```bash
cd GewCoordinator
dotnet run -c Release
```

初回は `C:\Vector\GODIUS` を読み込みます。別の場所は「参照...」で指定してください (次回以降は記憶します)。

## できること

- 脚 / 体 / 頭 / 武器 / 盾の選択。種類 (ID 上位 3 桁) は直接入力でき、カラー (下位 2 桁) は別の欄で選びます
- 性別の切り替え (種類の先頭桁 `0xx` = 男性、`1xx` = 女性)。武器・盾の前後は性別で自動調整します (男性: 盾が前・武器が奥 / 女性: 盾が奥・武器が前)
- ポーズ、向き (4)、アニメ (3 コマ) の切り替え、アニメーション再生、左右反転、倍率変更
- ランダムコーディネート、コーディネートの保存 / 読み込み (JSON)
- 現在のコマの PNG 保存、全コマのシート PNG 保存

### ID の読み方

`B` + `5桁` + `2桁` + `.spr.NCS` (例: `B0100407.spr.NCS`)

| 部分 | 意味 |
|---|---|
| 先頭 1 文字 | パーツ (`B` 体 / `H` 頭 / `L` 脚 / `W` 武器 / `S` 盾) |
| 5 桁の上位 3 桁 | 装備の種類。先頭桁が `0` で男性、`1` で女性 |
| 5 桁の下位 2 桁 | カラーバリエーション (体: ハニー / ピュア / ブリーチ / クリーム / ロイヤル、脚: ゴールド / シルバー / ブロンズ / レッド / ブルー / ブラウン / アイアン) |
| 末尾 2 桁 | ポーズ |

ポーズ 0 は歩行 (コマ 1,2,1,3,1 の繰り返し)。1 は攻撃、6 は防御、7 は座りと推定。2〜5 は素手の動作で用途は未確認です。

## スプライト形式 (`EAST`)

リトルエンディアン。

```
Header : "EAST", u16 version(0x30), u16 frameCount, u16 0, u32 offsets[frameCount + 1]
         (オフセットはテーブル直後が基点。最後の値はデータ末尾)
Frame  : u32 0, u16 height(120), 15 byte の行ビットマップ (bit y が立つ行だけ格納)
         立っている行ごとに: u8 n, n 個の (u16 skip, u16 len, len 個のパレット番号)
         1 行の skip + len の合計は常に 136
```

- 画像は 136 x 120 の共通キャンバスで、全パーツが同じ座標系なので、そのまま重ねられます
- 透明になるのは skip で読み飛ばした画素だけです。**パレット番号 0 は不透明の黒**です
- パレットは `Data\Default.pal` (256 色 x B,G,R,X)
- 1 ファイルにフレームが 12 枚あり、4 向き x 3 コマの並びです

参照実装: [`tools/spr.py`](tools/spr.py) (Python + Pillow)、[`GewCoordinator/Sprite.cs`](GewCoordinator/Sprite.cs)

## 動作確認用のヘッドレス描画

```bash
GewCoordinator.exe --render out.png B=3601 H=105 L=900 W=6900 S=0 pose=0 frame=7 behind=W
```
